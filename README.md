## Cómo Ejecutar este Proyecto

1. Clona el repositorio:

```bash
git clone https://github.com/jonmolinna/Portafolio.git
cd Portafolio
```

2. Instala las dependencias:
   $ npm install

3. Ejecuta el servidor de desarrollo:
   $ npm run dev
